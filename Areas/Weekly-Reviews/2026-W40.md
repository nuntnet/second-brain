- **Oathkeeper Rule ไม่ระบุ config = ใช้ staging Kratos:** rule dev ที่ไม่ specify config จะ point ไป `kratos-public.share` (staging) → ปฏิเสธทุก dev session — ต้อง explicit เสมอ
- **BOLA ไม่เคยมี ArgoCD Application ของตัวเอง:** ค้นพบจาก cluster — rule ฝากอยู่ใน bridge-development มาตลอด
- **`bola_beta_free` ไม่ auto-assign:** บริษัทใหม่ไม่มีแผน quota → `CreateWorkspace` ส่ง 503 ทันที (ดูเหมือน error หลอก) — ยังไม่รู้ว่าใครมอบ

### Tooling / Auth
- **Claude Code OAuth:** ส่ง `http://localhost:<port>/callback` เสมอ — ไม่ใช่ 127.0.0.1; Hydra client ต้องลงทะเบียน port ให้ถูก
- **Headless MCP eval กับดัก:** อย่าเปลี่ยนชื่อ server config ขณะ eval รัน — credential หาย; multi-company user เรียก whoami ก่อน = design ที่ถูกต้อง
- **backfill_kratos_ids / backfill_bola_registry รันไม่ได้จริง:** binary ไม่ build เข้า image + env var ผิดชื่อ + ขาด system token

### Business Logic
- **LINE OA channel_id globally unique:** ข้ามทุก workspace ทั้งระบบ — ย้าย OA ต้อง delete ที่เก่าก่อน ไม่มีทางลัด
- **`BindExistingBolaWorkspace` เขียน company_id เองในคำสั่งเดียว:** CCS bind + BOLA write ไม่ต้องทำแยก

### Code Quality
