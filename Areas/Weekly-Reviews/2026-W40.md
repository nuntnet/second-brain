## 🧠 Things Learned

1. **SQL injection จับโดย review bot** — full-diff review เห็นสิ่งที่ผ่านตามนุษย์ไป; ทำทุก MR ใหญ่
2. **Headless MCP eval กับดัก** — ห้ามแก้ config server ชื่อซ้ำขณะ eval รัน (credential หาย → needs-auth ทั้งหมด)
3. **Oathkeeper dev = staging scope** — enforce `user.read offline` เหมือนกันทั้งสอง env; debug ด้วย `kubectl logs -n share deploy/oathkeeper`
4. **LINE OA globally unique** — channel_id = unique ข้ามทุก workspace ทั้งระบบ; ย้าย = delete ก่อนเท่านั้น
5. **backfill tools พัง 2 ตัว** — `backfill_kratos_ids` (binary ไม่เข้า image, env ผิดชื่อ) + `backfill_bola_registry` (binary/dry-run/X-User-Id)
6. **BOLA Rule ไม่ระบุ config = ใช้ staging Kratos** — dev session ถูกปฏิเสธทั้งหมดถ้าไม่ระบุ `kratos-public.share-dev`
7. **บริษัทใหม่ 503 = quota ไม่ใช่ flag** — `bola_beta_free` ไม่ได้ assign อัตโนมัติ (ยังไม่รู้ว่าใครมอบ)
8. **`BindExistingBolaWorkspace` ทำทีเดียว** — CCS bind + BOLA write ในคำสั่งเดียว (ค้นพบจากโค้ด)
9. **Company name rules ต่างกัน** — CCS = 2–128 char; OC2Plus = 5–50, Thai/Latin/digit เท่านั้น (เข้มกว่า)
10. **Codex CLI บน dev** — ต้องใช้ share-dev หลัง !195; dev เดิมไม่มี RFC 9207
