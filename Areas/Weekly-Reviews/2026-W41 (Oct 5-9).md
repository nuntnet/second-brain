## 🧠 Things Learned

### AI / Architecture
- **RAG vs. Context Window Caching** — สำหรับ KB เล็กๆ structured ไม่กี่ไฟล์ ส่งทั้ง doc เข้า context ดีกว่า RAG มาก; chunk size ทำให้ context สำคัญหาย; Milvus อาจ drop ได้ถ้า KB ไม่ขยาย
- **Space Go architecture** — ต้องชัดเรื่อง Store → Provider → QMS plan assignment ก่อนออกแบบ multi-tenant ไม่งั้น scope ลอย

### Patterns / Process
- **Manus as supervisor** — pattern ใหม่: Manus อ่าน diff ตรวจ; Claude Code implement เฉพาะ Read/Edit/Write เท่านั้น ลด hallucination ใน complex review
- **Idempotency rule** — อย่าใช้ "ค้น history ไม่เจอ = ยังไม่สำเร็จ" มี race condition + paging issue จริง ใช้ `transaction_code` หรือ idempotency key แทน

### ch-erawan
- **Centralized auth** — Better Auth กำลัง extend รองรับ unified flow (session ยาว ~6h วันเสาร์)
- **ADAM SPS + Node.js** — DMS Phase 3 ใช้ Node.js layer ไม่ใช่ direct PHP — ยืดหยุ่นกว่าและ type-safe กว่า
