## 🧠 Things Learned สัปดาห์นี้

### Architecture / System Design
- **CCS2 tenant vs system**: `provider.sellsuki.local` = tenant admin, `system.sellsuki.local` = system admin — Provider Management ต้องอยู่ในระดับ system เท่านั้น
- **White-label isolation**: แต่ละ white-label มี domain + IdP แยกกัน ทำ cross-switch ไม่ได้
- **in-app browser SSO loop**: ERR_BLOCKED_BY_CLIENT บน cross-host fetch → redirect loop; ต้องอ่าน session จาก same-host endpoint แทน
- **BOLA auth ownership**: centralized roles via portal ดีกว่า copy-paste ใน 4 ที่ — ลด debt ระยะยาว

### Backend / Infra
- **rag-core boot**: บังคับมี `PROVIDER_ID` + `COMPANY_ID` ตั้งแต่ `APP_ENV=staging/prod` — null UUID เป็นแค่ placeholder ชั่วคราว
- **Sellsuki ยังไม่มี company ของตัวเองในระบบ**: ต้องสร้างผ่าน Platform team ก่อน push prod
- **Messaging pod resource**: 500m/512Mi over-provisioned มาก — 100m/128Mi รันได้สบายใน production
- **Kafka topics**: ต้องสร้างแยก (KafkaTopic YAML apply เอง) ไม่ได้มาพร้อม deploy secret
- **Local git tags can go stale**: เช็ค remote tag ก่อนตัดสินใจว่า release ships อะไร
- **GitLab runners shutdown weekends**: offline ตั้งแต่ศุกร์ 21:05 กลับมาจันทร์ 09:00

### Facebook / OAuth
- **Facebook webhook registration**: ต้องการ actor Kratos user ID + subscribe fields ใน Meta dashboard ด้วย
- **Facebook signed-request**: `verifySignedRequest` → 400 = empty payload หรือ HMAC fail (ต้อง debug)
- **Google consent "Testing" mode**: กั้น non-test users จริง — ต้อง Publish ก่อน launch จริง
- **`drive.file` scope**: ให้สิทธิ์เฉพาะไฟล์ที่ user เลือก; โฟลเดอร์ต้องใช้ `drive.readonly` (restricted scope → เจอ Google verification warning)
- **GitLab CI variable scope**: ต้องพิมพ์ environment name ใน scope แล้วเลือกจาก dropdown — ถ้าทิ้ง `*` จะชนกับ variable เดิม บันทึกไม่ได้

### Process / Tool
- **Colony bot pattern**: คอมเมนต์ตีหนึ่งถึงตีสี่, มีแท็กเครื่องจักร `[ant-colony:epic-done:SG-11]` — ไม่ตอบ Jira comment ทั่วไป ต้อง escalate หาคนดูแลโดยตรง
- **PHP include order**: `config.php` ต้อง include ก่อน check API key — เป็น root cause ของ ADAM SPS /api/slots 502
- **BOLA invite 403**: Cloudflare 403 บน `accounts.sellsuki.com` เป็น infra issue ไม่ใช่ code bug — ต้องแจ้ง SRE
- **MRs ที่คิดว่ายังรอ บาง MR merge ไปนานแล้ว**: AI-249/251/253 merged แล้วแต่ Hermes ledger มี status ผิด — ต้อง cross-check กับ git จริงเสมอ
