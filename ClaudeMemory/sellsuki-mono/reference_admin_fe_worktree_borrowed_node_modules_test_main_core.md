Seen 2026-10-29 (AI-344). Symlinking `node_modules` for root, apps/admin and packages/* from `/Users/nunt/sellsuki_mono/frontend/ai-chat-admin-frontend` avoids a pnpm install, but:

- `apps/admin/node_modules/@admin/core -> ../../../../packages/core` resolves through the symlink's real path → the main checkout's core. A test in apps/admin passes or fails against main's core, not the branch's.
- `packages/core/node_modules` via symlink is broken (`Cannot find module …/vitest.mjs`); run from apps/admin with `--root ../../packages/core`.
- `npx tsc --noEmit` in apps/admin: ~239 errors from skew. Only errors in the branch's changed files mean anything.
- Remove the symlinks before `git worktree remove`.
