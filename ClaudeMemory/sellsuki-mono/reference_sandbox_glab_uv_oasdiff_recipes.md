Found 2026-11-09 porting the chat-core openapi gate REPAIRED branch to rag-core (AI-362, rag-core !74).

- **glab inside the sandbox fails** with `tls: failed to verify certificate: x509: OSStatus -26276`. Retry unsandboxed (`dangerouslyDisableSandbox`); cwd must be inside a sellsuki repo.
- **uv** in a worktree: `UV_CACHE_DIR=<scratchpad>/uvcache uv sync --extra dev --frozen` (default `~/.cache/uv` is write-denied). Run via `rtk proxy` to see raw output.
- **oasdiff v1.35.0 locally**: `go install ...@v1.35.0` fails (toolchain download denied, "does not contain package"). Build from the module cache instead: `cd ~/go/pkg/mod/github.com/oasdiff/oasdiff@v1.35.0 && GOTOOLCHAIN=local GOFLAGS=-mod=mod GOCACHE=<scratch>/gocache GOPROXY=off go build -o <scratch>/bin/oasdiff .` (`--version` prints "main", that is normal). `rtk` hides build errors; use `rtk proxy`.
- **oasdiff `install.sh`** pins by env var: `curl .../oasdiff/v1.35.0/install.sh | version=1.35.0 sh` (no `v`, not a positional arg). The review bot guessed the positional form and was wrong; read the script at the tag before obeying it. The install log never prints the version, so add an `oasdiff --version` check in CI.
- **Gate-test fixtures must be version-stable**: widening a response enum is ERR in oasdiff v1.35 but only a warning in newer releases. Use a removed endpoint as the "real break" fixture.
- rag-core's gate (`scripts/ci-openapi-breaking-check.sh`) is JSON, one snapshot, regenerated by `make export-openapi`; its test shims `make`.
- A bot Result line with SHOULD FIX blocks a merge under the standing approval, even when it says "does not block merge" (see [[feedback-read-review-bot-before-merging]]).
