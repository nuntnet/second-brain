## Things Learned

- **Review-bot จับ SQL injection จริง (OC-4629 !666):** full-diff review คุ้มเสมอ — bot เห็นสิ่งที่ผ่านตามนุษย์ไป
- **BOLA Rule ไม่ระบุ config = ใช้ staging Kratos:** Oathkeeper ตัวเดียวใน cluster ใช้ค่ากลาง = `kratos-public.share` (staging) → rule dev ที่ไม่ระบุ config ปฏิเสธทุก dev session
- **BOLA Oathkeeper rule ฝากอยู่กับ `bridge-development`:** ไม่มี ArgoCD Application ของ BOLA เองเลย (ค้นพบจาก cluster)
- **`BindExistingBolaWorkspace` เขียน `company_id` ให้เองในคำสั่งเดียว:** CCS bind + BOLA write ไม่ต้องทำแยก (โค้ดค้นพบ)
- **บริษัทใหม่ 503 = ไม่มีแผน quota ไม่ใช่ flag:** `bola_beta_free` ไม่ถูก assign อัตโนมัติ → สร้าง workspace ไม่ได้ (ยังไม่รู้ว่าใครมอบแผนนี้)
- **backfill tool พัง 3 ชั้น:** (1) binary ไม่ถูก build เข้า Docker image, (2) `-dry-run` ไม่อ่านทะเบียน CCS จริง, (3) `BindExisting` ไม่ส่ง `X-User-Id` → CCS ปฏิเสธ (ไม่มี system token)
