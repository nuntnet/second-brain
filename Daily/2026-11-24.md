## Things Learned Today

1. **CCS2 architecture**: Provider management screen ที่ถูกต้องต้องอยู่ใน system admin (system.sellsuki.local), ไม่ใช่ tenant (provider.sellsuki.local)
2. **White-label switch**: แต่ละ white-label tenant มี domain + identity provider แยกกัน — cross-switch ไม่ทำได้จาก provider.sellsuki.local
3. **in-app browser SSO**: ERR_BLOCKED_BY_CLIENT บน cross-host fetch จะทำให้ redirect loop — ต้องอ่าน session จาก same-host endpoint แทน
4. **rag-core boot**: บังคับมี `PROVIDER_ID` และ `COMPANY_ID` ใน env เมื่อ staging/prod — ต้องสร้าง Sellsuki company UUID ให้ครบ
5. **Facebook webhook registration**: script `register-prod-fb-app.sh` ต้องการ actor Kratos user ID, Verify token คืนมาแล้วต้อง subscribe ใน Meta dashboard ด้วย
6. **BOLA invite flow**: Cloudflare 403 บน `accounts.sellsuki.com` เป็นต้นเหตุที่ user invite ไม่ผ่าน — ไม่ใช่ code bug แต่เป็น infra
7. **AI cost metering (AI-461)**: วันของแต่ละ company ไม่ตรงกัน + ต้องแยกได้ระหว่าง ai-chat / oc2plus / bola → ต้องแสดง daterange ชัดและ filter per-service
