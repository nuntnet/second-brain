## Things Learned

- **CCS3 hotfix pattern:** ถ้า main มี commits ที่ยังไม่ release ของทีมอื่น → ให้ตัด hotfix branch แยก ไม่ tag จาก main
- **go test `-p` flag:** จำนวน parallel packages; `-p 1` ป้องกัน resource contention บน shared dev machine
- **Colony bot detection:** comments ขึ้นต้น template เดิมทุกครั้ง + มี tag `[ant-colony:…]` = bot automation ไม่ใช่คน แม้ว่า Jira account type จะเป็น `atlassian`
- **AI card audit patterns:** cards ส่วนใหญ่ไม่ผ่าน po-team review เลย — "outside-world AC in a build card" (6 cards) เป็น class ที่เยอะที่สุด
